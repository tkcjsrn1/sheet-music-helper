## 재현된 원인과 수정

기존 처리 중 다음 버튼은 state=disabled지만 배경이 활성과 같은 초록색(#2CC985/#2FA572)이었고 쪽 표시줄은1/2만 보여 처리 중이라는 사실이 없었다. 완료된 두 쪽 뒤 새 작업을 시작하면 count<2에서 반환해 숨겨진 버튼의 state=normal도 남았다. 또한 worker가 _show_result를 먼저 예약하고 별도 finished에서 _converting을 끄므로, 결과를 공개한 순간에는 쪽 선택이 여전히 거부됨을 다쪽/PDF 회귀에서 확인했다. **사람 PC의 정확한 1분 지연이나 둘째 쪽 미처리라는 추측 자체를 동일 환경에서 확정한 것은 아니다.**

완료 공개는 finished에서 잠금을 푼 뒤 한 번 수행한다. 모든 버튼 상태는 결과가0/1쪽이어도 갱신하고, 비활성은 회색/활성은 기존 테마 색을 쓴다. 처리 중 쪽 표시줄에 `2쪽 처리 중… · 2 / 전체 처리 중`과 움직이는 막대, 합본 단계에는 `결과 합치는 중…`을 표시한다. 실제 완료율을 추측한 퍼센트는 넣지 않았다. 번호/전체 수와 활동 막대로 구분한다. 기존 변환 중 쪽 선택/편집 보호·실패 쪽 계속 처리·출력 파일과 인식 경로는 유지한다.
