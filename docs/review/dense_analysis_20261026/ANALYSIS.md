## 코드/자료가 설명하는 원인

- 기본 renderer는 각 음 근처 후보에서 원본 잉크·다른 라벨·기둥 등을 피한다. `ink_ok=text_w*2`, 근접 배치 완화 같은 기존 예산이 있어 **원래 배치도 원본과 교차0을 보증하지 않는다**. #407의 이동 보호는 기존보다 악화하지 않는 조건이며 기존 교차를 모두 제거하는 조건이 아니다. 이 상수는 이번에 바꾸지 않았다.
- 운지/아티큘레이션/이음줄과 높은 밀도의 화음이 같은 위아래 공간을 쓰면 안전한 이동이 대부분 거부된다. 이 방향은 그림·기존 제약이 뒷받침하는 설명이며 각 라벨의 정확한 탈락 사유를 새로 계측한 것은 아니다.
- 줄 옵션은 자기 x와 글자 크기를 유지하고 원본의 비흰 화소를 보호한다. 한 보표라도 공간이 없으면 쪽 전체를 기존 방식으로 돌린다. 기존 검증의 D♭1 전체262개 중 줄 이동0이므로 이 확대 구간도 개선0이다. 어느 보표가 첫 실패였는지는 현재 저장 로그에 없어 추측하지 않는다.
