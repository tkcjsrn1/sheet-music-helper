## 쪽 전환과 판단

계측/무계측 완료 후 2→1→2로 전환했고 모두 실제 쪽 번호가 즉시 바뀌었다. 전환(이미지 읽기·UI 공개·idle 갱신 포함)은 0.223, 0.185, 0.219, 0.250, 0.173, 0.214초였다. 처리 중에는 다음 버튼 disabled가 확인됐으며, 완료 후 두 쪽을 모두 공개한다.

**약1분 지연은 이번 최신 소스에서 재현 안 됨.** 현재 입력에서 기다린 시간은 주로 쪽 처리이고 UI 큐/쪽 전환 자체의1분 대기는 없었다. #301 이전 활성처럼 보이는 잠금 상태가 처리 대기로 오인됐을 가능성은 **(추측)** 이며 사람 PC의 예전 지연 원인으로 확정하지 않는다. 완료 후에도 반복되면 입력 두 장·처리 상태 문구·대기 시점을 받은 뒤 같은 도구로 재현해야 한다.

화음 구제/음자리표 관련 진단이 비교적 길지만 검출·판정 소유 파일은 수정하지 않았다. 속도만 위해 진단/보호를 생략하지 않는다. 현재 재현되는 새 결함이 없어 수정 PR 대신 도구/측정 기록 PR을 올린다. 제품 기본 PNG·JSON 네 파일은 계측/무계측 바이트 동일, SHA를 원자료에 보존했다. 전체검사는 직전 #308의 실패0·건너뜀0/골든711·PDF17 녹색과 같은 제품·검사 코드(diff0)를 재사용한다. 공식 빌드 뒤에는 전체검사를 다시 수행한다.
