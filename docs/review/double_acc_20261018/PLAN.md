**목표:** CLI가 종류를 확정해 준 유효 임시표 bb/##를 고정도·영문 표기와 MIDI −2/+2에 반영한다.

**환경:** 기존 Windows Python, 새 의존성 없음. 산출물 F:, 공유 C:/stash/기존 빌드 보존.

1. D4bb=60, F4##=67, B4##=73, C4bb=58 — 옥타브 경계와 조표 중복 적용 금지.
2. 이동도 C조 Dbb=도/F##=솔, G조 F##=도 — 고정도와 혼동하지 않음.
3. double_acc flag만 있거나 미확정이면 기존 값 그대로; check 제외 정책 유지.
4. 원래 double인 라벨을 사용자가 고치면 수정 표기가 재생에 우선, 원본 자료 불변.
5. 단일 #/b/natural/빈 값의 고정도·이동도·영문·경고 및 기본 PNG/JSON 바이트0.
