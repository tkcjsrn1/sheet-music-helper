# 실제 Windows 클릭 회귀

소스 GUI에서 자체 생성 작은 2쪽/확인 라벨을 사용해 계이름 달기·다음 쪽·다음 확인 필요를 실제 SendInput으로 눌렀다. 연결을 끊은 대조는3건 실패, 실제 연결은3건 통과. 변환 검사는 입력 도착과 잠금/요청 생성까지이며 작업 스레드만 대체한다. 실제 인식 완료를 이 검사로 주장하지 않는다.

각 클릭 직전 실제 커서 좌표·WindowFromPoint 최상위 창·PID가 일치한다. 커서 이동 실패/다른 위치로 제한되는 경우 입력을 보내지 않는 headless 검사도 수정 전 실패→수정 후 통과. 별도 읽기 전용 코드 검토 중요 문제0.

전체 실패0·건너뜀0, 골든711·PDF17와 PNG/JSON 바이트0 근거는 ../input_folder_20261014/이다. 폴더 PR이 병합된 뒤 제품/검사 코드가 이 실행과 동일하며 이번에 포함한 headless 검사도 이미 그 전체 실행에 들어 있었다. 실제 마우스 검사는 기본 run_all에 넣지 않고 명시적으로 실행한다. exe 실제 클릭은 새 빌드 때 별도로 한다.
