# 변환 중 여러 이미지 선택의 상태 혼합 방지

기준 main `3531ba3`. `_set_input`은 변환 중 원본 변경을 거부하지만 `select_images`는 그 뒤 입력 목록과 파일 이름 표시를 갱신했다. 기존 원본·작업 요청은 유지되고 다음 입력 목록만 다른 파일로 바뀌는 상황이었다. 현재 변환 결과의 인식 오류로 확대하지 않는다.

실제 소스 Tk 버튼과 모의 파일 대화상자로 [수정 전 실패](before.log)를 확인했다. 선택 적용 조건에 기존 `_converting` 검사를 더한 한 줄 수정이다. [수정 후](after.log) 원본 경로·입력 목록·파일 표시·고정 작업 요청을 유지하며 대기 상태의 정상 여러 이미지 선택도 동작한다. 단일 선택/기존 `_set_input`의 보호는 바꾸지 않았다.

[쪽별 기록 검사](pages.log)와 기존 전체 이미지/PDF 처리 검사 통과. [최종 전체 검사](final-tests.log) 실패0·건너뜀0, 골든711·PDF17쪽 스냅샷·기본GUI PNG/JSON 바이트 보존. [검사 시작/끝 코드 해시](source-hashes.json) 동일. 인식/판정/렌더링/골든 변경0.

재실행: `python tests/test_gui_snapshot.py`, `python tests/run_all.py`. 소스 Tk 검사이며 실제 exe 클릭 확인은 아니다. 기존 a200ccd exe에는 아직 미포함이다.
