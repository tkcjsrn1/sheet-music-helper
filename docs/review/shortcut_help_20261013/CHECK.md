# F1/? 단축키 도움말

F1은 입력칸에서도 도움말을 연다. ?는 입력칸에서는 문자로 남고 미리보기/라벨 목록에서는 도움말을 연다. 반복 입력은 기존 창을 사용하며 Escape/닫기로 종료한다. 본창·라벨 수정·추가 창에 같은 함수를 연결했다. N/P 입력 보호는 기존 규칙을 공유한다.

경로 부재 red → 실제 Tk 키 입력 5검사 green. 글자 입력 유지·반복 창·Escape·라벨 문서/저장 파일 무변경을 확인했다. source GUI 실제 작업자 Aoharu1/D♭1/바흐1 PNG/JSON6파일은 기존 baseline과 바이트 동일(SHA default.json). 이후 main22065ab(제품 변경0)을 수신해 단독 전체 검사 41/41, 실패0·건너뜀0, 골든711/PDF17 무변경. 처음 두 중단 실행을 통과로 세지 않았다.

exe 직접 클릭/화면/스피커/다운로드 SmartScreen 검증이 아니다. 새로운 의존성·인식/판정·골든 변경0. 원본·exe·ZIP은 포함하지 않았다. 이전 night_queue_20261013/CHECKPOINT.md는 당시 미완료 기록이며 이 문서가 3(a)의 완료 기록이다.
