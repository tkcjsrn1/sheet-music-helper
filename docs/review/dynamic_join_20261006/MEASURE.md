## 공통 함수의 최소 수정

`_refine_y`에서 원본 연결 성분과 처리 뒤 덩어리를 대조한다. 이미 계산한 band_lab/band_stats를 재사용한다. 서로 다른 원본 성분이 처리 뒤 덩어리에 들어왔을 때, 단독으로 기존 타원 커널의 침식을 견디는 성분이 정확히 하나 있고, 나머지 성분의 세로 범위가 겹치지 않으며 덩어리 내부의 머리 조각으로 해석될 수 없을 때만 그 성분의 잉크로 중심을 구한다. 모호하면 기존 창을 유지한다.

기존 closing/opening 커널, 후보 생성·삭제, 머리 분류, 음고 계산, 행 밀도 문턱은 그대로다. 여백은 기존 커널 크기로 결정하며 새 실측 상수를 넣지 않는다. CLI·GUI·보강 검출에서 같은 검출 함수를 사용한다. candidate-snippet.txt는 측정한 삽입 코드다.

단순히 독립 성분 하나를 고르는 초기 진단은 49원본+x0.5의 13,247회 중심 계산 중 124개 복합 성분, 102개 잠재 중심 변화를 관측했다(component-probe.json). **이 102개를 수정한 것이 아니다.** 원본 머리 조각을 버릴 위험이 있어 세로 분리·내부 조각 보호를 넣은 더 좁은 사본만 채택했다.

## 한계와 재현 자료

원본에서 이미 붙은 기호, 모호한 복합 성분, 사진 전체의 정확도는 이 수정으로 보장하지 않는다. 실수 좌표/반올림/커널 크기 문제를 일반적으로 해결한 변경도 아니다. 알려진 다른 오인식·누락은 별도 과제로 남긴다.

compare_candidate.py/probe_components.py는 측정 당시 output의 원본 입력 목록·기준선·검출 사본을 사용한 재현 자료다. 완전한 독립 실행 패키지가 아니며 원본 악보·exe·ZIP은 포함하지 않는다. 제품 반영 뒤 전체 검사는 tests.log의 **39/39·실패0·건너뜀0**으로 확인했다(골든711·PDF17쪽·#52 포함). 합성 사진 12입력의 실제 --photo 경로도 전체 JSON·PNG 바이트 동일(photo-report.json). 실제 촬영본 전체의 보존을 주장하지 않는다. 새 exe 검증은 빌드 뒤 릴리스 폴더에 별도로 기록한다.
