# PR #407을 지금 병합해도 되는가 — 판단 자료만

병합은 사용자 결정이며 자동 병합하지 않는다.

현재 고정12쪽4721라벨에서는 새 원본 잉크 교차·숫자/기호 가림·원본화소 악화0이고, 전체검사 실패0·건너뜀0, 골든711·PDF17 유지다. 기존 탐색 잉크 예산은 이동에 쓰지 않고 원본 RGB까지 검사하므로, 기각된 첫 시안보다 안전 근거가 강하다. 라벨수/원음표좌표/음고/표기/등급/JSON 변화0도 확인했다.

다만 「배치 일관성을 개선했다」는 채택 근거는 약하다. 572개 이동을 취소해12개만 남았고, D♭1/Aoharu1~3 PNG는 기존과 바이트 동일하다. 방향 반대395→395, 먼 라벨128→128, 자기중심 일치3356→3346이다. 추가 후처리 복잡도에 비해 사용자 체감 이득은 작다.

결론: **측정 범위에서 새 가림 없이 통과한 제한적인 배치 변경**으로는 병합 검토가 가능하다. 그러나 보편적 안전 보장이나 들쭉날쭉 해결이라고 부를 수 없다. 일관성 개선을 목표로 한다면 지금 보류해도 기능 손실은 거의 없다. 오선행±1px 제외 정책은 여전하여 그 행에 겹친 다른 기호를 의미별로 분리하는 모델도 아니다. 사진 파생 입력과 새 GUI 직접 클릭은 미검증이다.

이번 계이름 줄 시안은 #407을 병합하거나 의존하지 않고 origin/main에서 따로 만든다. #397 등 인식 후보·기준 갱신은 섞지 않는다.
