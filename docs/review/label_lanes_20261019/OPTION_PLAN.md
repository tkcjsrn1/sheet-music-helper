# 계이름 줄 선택 옵션 — 승인 내용과 구현 순서

사용자 승인(10-20 재개): #407·#414·#427은 main에 병합됐다. 최신 main 내부 베타를 먼저 마친 뒤 #412를 선택 옵션으로 다듬어 PR까지만 갱신한다. 그림 판정 전 병합하지 않는다.

## 변경 경계

- renderer: 기존 함수에 `placement_mode="near"` 기본 인자, `layout_status` 선택 출력. 기존 호출의 PNG와 인식 객체 불변. lanes에서 기존 크기/확신도/자기 x/높은 음 위 순서를 유지한다.
- 전용 줄은 각 보표 바깥에서 가장 가까운 후보부터 찾는다. 원본 비흰 화소(흰 테두리·점선 포함)와 새 라벨을 가리지 않는다. 셈여림/페달을 식별하는 새 인식기는 만들지 않으며 잉크 검사로 그 안쪽 빈칸을 먼저, 없으면 바깥 빈칸을 찾는다. 기존 .9sp 근접 열은 리듬 없는 그림용 휴리스틱 그대로다.
- 보표 경계는 이웃 보표 내부를 침범하지 않는 범위. 모든 보표를 계획한 뒤에만 그린다. 하나라도 못 놓거나 보표 정보가 빠지면 페이지 전체를 기존 배치로 되돌리고 `layout_status`에 안내를 반환한다. 일부 보표 혼합 금지.
- GUI: 표시 방식 `음표 옆(기본)` / `계이름 줄`, 기본 near. settings 저장·검증·복원 및 기존 report_settings의 변환 시작 스냅샷에 반영한다(새 dataclass 필드는 불필요). 작업 중 설정 변경이 돌고 있는 변환을 바꾸면 안 된다.
- 수정본: lanes 선택 때만 render_options에 placement_mode를 저장하고 재열기 허용 목록/값 검증으로 복원한다. 기본 near의 PNG/labels JSON은 기존 바이트 유지한다. render_options에는 near 값을 새로 쓰지 않으며, settings/report_settings는 새 선택 값을 저장하는 용도라 인식 JSON과 구분한다. labels_io와 인식/판정 파일은 수정하지 않는다.
- 공간 부족 안내는 GUI 로그 및 현재 쪽 표시줄에 유지한다. 다른 쪽으로 이동/재열기해도 해당 쪽 상태를 표시한다.
