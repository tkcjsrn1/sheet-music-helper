# 현재 쪽 확인 필요·주의 라벨 순회 — 2026-10-12

기준 main `7fe91c6`, 최신 자료/도구 PR #299·#300 수신 뒤 `66106b1`에 통합. 두 병합은 제품·기존 검사 코드 diff0이며 Claude 문서/자료를 그대로 보존했다. 변경은 GUI 미리보기 선택·스크롤과 사용법뿐이다. 인식·판정·렌더링·설정 기본값은 바꾸지 않았다. 기존 d6cf163 exe에는 이 기능이 없으며 재빌드 조건은 별도로 확인한다.

## 동작

미리보기 위의 「다음 확인 필요 ▶ / ◀ 이전」으로 현재 쪽의 check·caution을 보표 순서, 보표 안 왼쪽→오른쪽으로 선택한다. 동일 좌표·음고·글씨가 여러 번 나와도 안정된 렌더링 순서의 출현 번호로 자기 배치를 선택한다. 첫 이동 전에는 `0 / 전체`, 선택하면 `현재 / 전체`이다. 처음·끝에서는 해당 방향 버튼을 비활성화하며 다른 쪽으로 넘어가지 않는다. 선택 영역을 적용했다면 그 영역에 남은 라벨만 순회한다.

라벨을 파란 테두리로 강조하고 가로·세로 스크롤을 이동한다. 수정 창이 열려 있으면 같은 라벨을 선택하며, 먼저 이동한 뒤 수정 창을 열어도 그 라벨을 선택한다. 사용자가 고친 라벨은 기존 저장 정책대로 진하게 그려지므로 순회 대상에서 제외한다. 이동만으로 확인 완료나 사용자 수정으로 기록하지 않는다.

수정·삭제·되돌리기·영역 변경 후 개수를 다시 계산한다. 새 입력·쪽 변경·수정본 재열기는 선택 위치를 초기화한다. 처리 중이거나 미리보기 파일을 열 수 없으면 순회하지 않는다. 강조는 Canvas에만 그리며 PNG·JSON에 저장하지 않는다.
