# 조표 머리 표시 재검증 — 2026-10-02

PR #137의 조표 문구는 Unicode ♯/♭ 대신 라벨과 같은 ASCII #/b를 쓴다. 표시층만 바꾸며 입력 JSON의 조표 기호·라벨 좌표·음고·확신도는 그대로다. 사용자가 조성을 지정하면 문구 끝에 `(사용자 지정)`을 붙인다. 사용자 조성의 ♯/♭ 입력도 표시할 때 ASCII로 바꾼다.

| 결과 | 머리 문구 | 라벨 수 | 머리/범례 겹침 | 변경한 자리의 기존 잉크 |
|---|---|---:|---:|---:|
| [Aoharu 1쪽](aoharu_p1.png) | 조표: # 2개로 읽음 | 226 | 0 | 0 |
| [쇼팽 D♭ 1쪽](chopin_Db_p1.png) | 조표: b 5개로 읽음 | 255 | 0 | 0 |
| [바흐 1쪽](bach_p1.png) | 조표: 없음으로 읽음 | 185 | 0 | 0 |

같은 입력의 머리 없는 기준선과 라벨 JSON 전체가 세 장 모두 일치한다. 새 머리 픽셀의 경계 상자와 범례 경계 상자는 분리돼 있고, 그 위치는 기존 원본·라벨 잉크가 없는 밝은 여백이다. 이 PNG에는 GUI 기본 범례도 함께 넣었다. 범례를 끄면 머리만 남는다.

`tests/test_result_legend.py`는 조표 없음/1~7개·사용자 지정 문구·범례의 모든 글자를 실제 Pillow 글꼴 마스크로 검사한다. 기본 글꼴과 설치된 GUI 제공 글꼴(맑은 고딕/굵게/굴림/바탕)의 빈 마스크 또는 미지원 코드포인트와 같은 네모 글리프를 거부한다. 미지원 코드포인트로 검사 자체가 실패를 잡는지도 확인한다. 임의 사용자 글꼴은 사전 검증 대상에 포함되지 않는다. 인식 코드·판정 문턱·골든 파일은 바꾸지 않았다.
