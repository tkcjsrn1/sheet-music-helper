## 3. 가르는 근거 (오선 제거 영상, 라벨 중심 ±0.3sp 열의 중앙값)

**[1] 겹빔 칸 — 위 · 아래가 빔 두께의 가로 막대로 막힌 흰 칸**
`흰 중심 · 위 · 아래 첫 잉크 ≤ 0.5sp · 두께 0.40~0.60sp(양쪽) · 가로 런 ≥ 1.5sp(양쪽)`
- 두께 0.40~0.60: 조판 빔 두께 0.5sp(Verovio 0.50 · LilyPond 0.48) ± 0.1. 걸린 유령 최대 0.57. 위쪽을 막으면 화음 이웃 머리(0.81~0.86, Schubert Leipzig 2개)가 빠진다
- 런 ≥ 1.5sp: 진짜 흰 중심 머리 6,907개의 95% 1.09(링 테두리 = 머리 폭), 걸린 유령 최소 1.55
- 기각 12(넓힌 마스크로 「한쪽만」)와 다르다 — **양쪽 다** 막힌 칸만, 마스크가 아니라 런 · 두께 실측. G1(기울어진 마스크, 기각 27 삭제 · §1-13 표시)과도 다르다 — G1은 2.5sp 열림이라 이 짧은 빔을 못 본다

**[2] 좁은 구멍 — 머리 링이라면 위 · 아래 테두리가 머리 폭만큼 이어진다**
`오선 밖 · 기둥 없음(< 2.5sp, _has_stem 길이) · 흰 중심 · max(위 런, 아래 런) ≤ 0.6sp`
- 진짜(같은 조건 120개) max 런 최소 **0.82**, 셈여림 유령 대부분 ≤ 0.45 → 기하평균 √(0.45 × 0.82) = 0.61
- 「왼쪽 아래로 뻗은 획(LD)」은 못 쓴다: 진짜 오선 밖 머리 LD 5% 0.14 · 중앙 1.88로 셈여림(0.28~0.96)과 겹쳐 진짜 46~51개가 걸렸다(규칙 초안 기각)
- 「같은 y에 3개 이상(글자 줄)」을 쓰지 않는 낱개 규칙이지만 기각 15(낱개에 덧줄/기둥 없음 → 삭제)와 다르다 — 덧줄 · 기둥이 아니라 구멍 폭이 판정이고, 표시안이다
