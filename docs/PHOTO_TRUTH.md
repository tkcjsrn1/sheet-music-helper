## 4. 사진 모드 A-25 경계만 켬 — 제품 구현 판정 (2026-10-04, PR 열림 · 병합 안 함)

`accidental_detect.annotate_accidentals`의 전파 경계를 사진 모드에서도 `_propagation_barlines`로(♮ · ♯ · G3 · H3는 끈 채). 사진 51장(`measure_photo_truth.py run_a25` → 변형 a25):

| 조건(사전 승인) | 결과 | |
|---|---|---|
| 표기 틀림 ≤ 88 | 137 → **88** | 맞음 |
| 나빠지는 사진 ≤ 3 | **3**(§2와 같은 3장) | 맞음 |
| 사진 아닌 입력 바이트 무변경 · run_all | 골든 711 · PDF 스냅샷 변화 0 · **27/27** | 맞음 |
| **오삭제 0** | 사라진 라벨 11 = 유령 10 · **진짜 머리 1** | **어긋남** |

오삭제 = 쇼팽 original__blackframe 보표 6 (2258, 3028) 「레b」(§3과 같은 자리, 2도 화음의 유일한 라벨). **원인**: `remove_accidental_ghosts`는 「임시표가 붙은 음표의 왼쪽 0.5~1.6sp · 같은 높이 빈 후보 = 그 임시표 글리프」로 지우는데,
판단 기준이 **인쇄된(원시) 임시표가 아니라 전파까지 반영된 실효 임시표**다. 경계가 맞아지며 전파가 늘면 글리프가 없는 자리의 진짜 빈 머리 · 붙은 화음 머리까지 「글리프」로 지운다.
§3의 오삭제도 같은 경로였다(G3로 적은 것은 잘못 — 정정).
**사진 아닌 입력에도 같은 구조가 있다**(A-25 경계는 이미 켜져 있음) — 거기서 오삭제가 났는지는 아직 안 쟀다.
**수정안**: 그 규칙의 기준을 원시 임시표(글리프가 실제로 검출된 음표)로 — 판정 변경이라 승인 필요.
