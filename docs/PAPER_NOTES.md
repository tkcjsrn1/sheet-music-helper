# 논문 재료 분류 — 규칙 기반 악보 인식에서 조용한 실패가 어떻게 숨는가, 그리고 그것을 찾는 검증 방법

**글이 아니라 재료 목록이다.** 절마다 숫자와 근거 문서만 모았다. 문장은 사람이 쓴다.
숫자는 2026-09-22 기준이고, 근거 문서에 측정 조건이 있다. 인용 전에 그 문서의 조건·한계 절을 확인할 것.

---

## 1. 문제 — 라벨 기준 평가는 오삭제를 원천적으로 못 본다

| 재료 | 숫자 | 근거 |
|---|---|---|
| 라벨→원본 한 방향 판정은 사라진 음을 대조 대상으로 삼지 못한다 | 811개 대조·전수 판정 어디에도 임시표 오삭제 7건이 없었다 | `ACCIDENTAL_GHOST_MEASURE.md` §5 · `BIDIRECTIONAL_VERIFY.md` · `VERIFIED_SCORES.md` 「전수 판정의 한계」 |
| 전수 판정(쇼팽 D♭ 1쪽 라벨 320개)으로도 놓쳤다 | 같은 쪽을 음표 쪽에서 세니 오삭제 24(10.0%) · 음고 오류 10(4.2%) | `OMISSION_RATE.md` §1·§3 |
| 근사 검사가 유령을 과소 집계 | `--verify` 4.5% → 전수 확대 26.6% (쇼팽 1쪽) | `DECISIONS.md` 기각 10 · README 「검증된 조건」 |
| 「음고 오표기 811개 중 0」 철회 | 라벨 쪽 0 → 음표 쪽 D♭ 1쪽 4.2% | `VERIFIED_SCORES.md` (철회 표시) · `OMISSION_RATE.md` |
| 합성 픽스처에서도 아무도 음표 수를 안 셌다 | 조표 픽스처 168 정답 중 18개 소실을 뒤늦게 발견 | `VERIFIED_SCORES.md` 「조표 픽스처 15종」 · `FIXTURE_LOSS_TRACE.md` |
| 오삭제와 유령은 대칭이 아니다 | 유령은 사용자가 보고 넘기지만 지워진 음은 알아챌 방법이 없다 | `COLLAB.md` §3-1 · `DECISIONS.md` §3-5 |
| **★ 핵심 대비 — 실패가 드러나는 방식 (수정됨, 아래 단서 필수)** | 원본 그대로면 **Audiveris의 실패(RE:Aoharu)는 출력 없음으로 드러나고, 우리의 실패(쇼팽 D♭ 1쪽)는 정상처럼 보이는 결과 안에 숨는다.** 그러나 **같은 캡처를 그레이스케일로 저장만 하면 Audiveris도 출력을 내고, 그 안에 오삭제 12.4%(쌓인 온음표 화음)가 숨는다** — 조용한 실패는 규칙 기반 도구만의 문제가 아니라 **출력이 나오는 순간 어느 도구에서나 생긴다.** 「드러나는 실패 대 숨는 실패」를 도구의 성질로 쓰면 안 되고, **같은 도구가 입력 형식 하나로 둘 사이를 오간다**는 사례로 써야 한다 | `AUDIVERIS_COMPARE.md` §1·§1-1 · `OMISSION_RATE.md` §3 |

## 2. 방법 — 조용한 실패를 찾는 검증

| 방법 | 핵심 | 근거 |
|---|---|---|
| **실측 분포 기반 문턱 유도** | 두 독립 근거가 같은 지점을 가리키게(예: 조표 쌍 y 문턱 1.818 / 1.742 → 1.75), 기하평균으로 여유 균형 | `DECISIONS.md` §1-4 · §3 판정 원칙 · `BLOCKED_HOLE_FEATURES.md` §8-2 |
| 근거 없는 상수 목록화 | 상수마다 근거·여유를 적고, 여유를 모르면 「맞다」가 아니라 「아직 안 깨졌다」 | `DECISIONS.md` §1-3 |
| **양방향 검증** (음표→라벨) | 소스 정답 대조, PDF 음표 머리 글리프를 정답으로 | `BIDIRECTIONAL_VERIFY.md` · `GOLDEN_EXPANSION.md` · `OMISSION_RATE.md` §2 · `tools/measure_omission_rate.py` |
| **골든 고정** | 전수 판정 711개를 매 커밋 기계 대조 + 문맥 골든(조표·음자리표·헤더) | `VERIFIED_SCORES.md` · `tests/golden/` · `tests/_score_context.py` |
| **좌표별 보호 검사** | 오삭제 18좌표를 좌표마다 독립 xfail — 하나 고쳐도 나머지가 안 가려짐, 가짜 수정으로 감도 확인 | `ACCIDENTAL_GHOST_MEASURE.md` §11 · `tests/test_naturals_real.py` |
| **사본 검증** | 후보 규칙을 제품 파일이 아닌 사본에 넣어 전 쪽 라벨·음고·문맥을 대조 | `BLOCKED_HOLE_FEATURES.md` §6·§9 · `tools/check_blocking_fix.py` · `tools/check_accidental_fix.py` |
| 관측 속성으로 표본 좁히기 | 가설로 좁히면 10건 중 7, `filled`로 좁히면 21건 중 18 | `DECISIONS.md` §3-0 |
| 역할 분리 | 만든 쪽이 검증하지 않는다(구현·독립 검증 교대) | `COLLAB.md` · WORKLOG 2026-09-22 PR #62 |
