# 쪽 넘기기·수정본 재열기 — 사람 PC 확인 순서

헤더 끝 수정이 포함된 다음 베타에서 사람이 확인할 절차입니다. 이 문서는 exe 직접 확인 완료 기록이 아닙니다. 스피커 청취·실제 다운로드 SmartScreen은 별도 미확인 항목입니다.

준비할 원본 PNG: `sample_images/KakaoTalk_20260731_162400402.png`(Aoharu 1쪽), `tests/fixtures/selftest/chopin_Db_p1.png`(쇼팽 D♭ 1쪽, 300dpi). 저장소가 없는 PC에는 테스트 담당자가 이 두 입력 파일을 따로 준비합니다. 결과 PNG를 입력으로 쓰지 않습니다. 원본은 보존하고, 확인용 복사본만 각각 `입력1-Aoharu.png`, `입력2-Db.png`로 이름 붙입니다.

1. 새 베타 ZIP을 새 폴더에 풀고 `악보헬퍼.exe`를 엽니다. 「사진 모드」는 끕니다. 「여러 이미지 선택」으로 위 복사본 두 장을 선택하고 「계이름 달기」를 누릅니다. **성공 2·실패 0**, 두 쪽 결과가 나와야 합니다.
2. 「이전 쪽·다음 쪽」으로 두 쪽을 오갑니다. **쪽 번호 1/2·2/2, 미리보기, 왼쪽 파일 이름이 함께 바뀌어야 합니다.** 두 번째 쪽에 보이는 라벨 하나를 클릭하고 원래 글씨와 위치를 적어 둡니다. 입력칸에 원래와 다른 글씨(예: 원래가 「도」면 「레」)를 넣고 「글씨 수정」을 누릅니다. **그 라벨만 진한 글씨로 바뀌고 주황 점선은 없어야 합니다.** 수정 창을 닫고 첫 쪽으로 돌아가 첫 쪽은 바뀌지 않았는지 확인한 뒤 다시 둘째 쪽으로 돌아갑니다.
3. 「라벨 수정 / 삭제」 창에서 「수정본 폴더를 다른 곳에 저장...」를 누르고 빈 저장 폴더를 고릅니다. 로그에 나온 **`사용자수정-…` 하위 폴더**를 적어 둡니다. 그 안에 결과 PNG·`라벨.json`·`사용자수정.json`·`재개정보.json`이 있고, PNG에서도 둘째 쪽의 수정한 글씨가 보여야 합니다. 폴더 안 파일을 옮기거나 일부만 복사하지 않습니다.
4. 프로그램을 껐다 켠 뒤 「수정본 폴더 다시 열기...」를 누릅니다. 3번의 **`사용자수정-…` 폴더 자체**를 고르고, 원본 선택 창에서 **`입력2-Db.png`**를 고릅니다. 수정한 둘째 쪽이 그대로 보이고 「사용자 수정 1건」 재열기 로그가 나와야 합니다. 재열기는 그 한 쪽을 여는 동작이므로 두 쪽 탐색 상태가 복원되는 것은 아닙니다. 원본이 없거나 다른 파일이면 열지 않고 이유를 안내해야 합니다.
5. 같은 라벨을 한 번 더 다른 글씨로 수정합니다. 「되돌리기」 한 번은 **저장했던 글씨**, 두 번은 **처음 적어 둔 원래 글씨**로 돌아가고 해당 라벨이 계속 선택돼야 합니다. 원래 check 라벨이면 마지막 취소 때 점선이 돌아오는 것은 정상입니다. 글씨를 다시 한 번 수정해 「수정본 폴더를 다른 곳에 저장...」로 새 폴더에 저장하고, **새 PNG와 미리보기 글씨가 같은지** 확인합니다. 기존 저장 폴더와 원본 PNG는 그대로 남아야 합니다.

결과 기록: 베타 해시 / Windows 버전 / 1~5번 각각 통과·실패 / 실패한 버튼과 실제 안내 / 가능하면 해당 부분 캡처. 원본 악보 전체가 보이는 캡처는 저장소에 올리지 않습니다.
