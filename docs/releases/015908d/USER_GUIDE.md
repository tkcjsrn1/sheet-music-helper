# 015908d 내부 베타 사용 안내

지금 확인하는 빌드는 **015908d**입니다. 친구·공개 배포 전 내부 확인용입니다. 이 문서는 안내 추가본이며 이미 받은 exe·ZIP은 바꾸지 않았습니다.

## 이번 베타에 포함된 보완

- **겹임시표:** 내림표나 올림표가 두 번 붙은 음을 `레bb`·`파##`처럼 표시하고 듣기 음높이에도 반영합니다. 잘못 읽을 가능성이 있어 주황 점선은 유지합니다.
- **화음 머리 되찾기:** 서로 붙은 화음에서 빠졌던 가운데 음이나 나란한 음을 더 찾습니다. 추가로 찾은 음도 원본과 비교해 주세요. 모든 누락이 해결된 것은 아닙니다.
- **화음 옆 임시표 묶음:** 화음 왼쪽에 모여 있는 내림표·올림표를 각 음에 연결하는 처리를 보완했습니다. 같은 마디 뒤 음에 이어지는 표시도 살펴봐 주세요.
- **계이름 배치:** 운지 숫자·덧줄·악상 기호를 더 가리지 않는 범위에서 일부 위치를 정리했습니다. 공간이 막히면 원래 위치를 유지하므로 들쭉날쭉함이 남습니다.

새 「계이름 줄」 선택 옵션과 화면 건반은 아직 초안이며 **이 베타에 들어 있지 않습니다**.

## 알아둘 한계

- 머리가 옆으로 엇갈린 화음에서는 일부 임시표가 다른 음에 붙거나 빠질 수 있습니다. 진한 글씨도 정답 보장은 아닙니다.
- **쉼표·음 길이·리듬을 읽어 연주하지 않습니다.** 듣기는 음높이 확인용이며 박자 없이 재생됩니다.
- 진한 글씨는 자동 판정에서 확실, 연한 글씨는 주의, 주황 점선은 확인 필요입니다. 연한 글씨·점선부터 원본과 대조해 주세요. 표시가 없는 누락도 있을 수 있습니다.
- 이 exe는 PDF를 직접 열지 않습니다. 선명한 PNG/JPG를 넣고 사진은 정면 촬영본에 사진 모드를 사용하세요. 기존 동봉 안내문의 스캔 해상도·꾸밈음·음자리표 관련 한계도 그대로입니다.

## 사용자가 확인할 목록

1. 두 장 이상 선택해 변환합니다. 다음 쪽이 처리 중에는 회색이고 완료 뒤 바로 넘어가는지, 쪽 이름·확인 필요 개수가 맞는지 봐 주세요.
2. 입력칸 밖에서 한글 상태 N/P로 확인 필요 위치를 이동하고, 영문 상태·NumLock 꺼짐에서 F1 도움말이 새로 열리는지 확인해 주세요.
3. 둘째 쪽 라벨을 수정·삭제·추가하고 되돌린 뒤 수정본을 저장합니다. 앱을 닫았다 열어 수정본 폴더를 다시 열었을 때 변경과 쪽이 유지되는지 봐 주세요.
4. 겹임시표·화음을 골라 표기와 들리는 높이를 비교해 주세요. 「확인 필요 음은 듣기에서 제외」가 켜져 있으면 점선 음은 건너뜁니다. 듣기는 박자 확인용이 아닙니다.
5. 이상한 곳은 「문제 신고용 저장」 ZIP과 쪽·위치·누른 순서를 함께 남겨 주세요. ZIP에는 원본 악보가 들어 있습니다.

자동 검증과 요청한 실제 exe 입력 검사는 통과했습니다. 스피커 청취와 실제 다운로드 SmartScreen은 사용자 몫입니다. 쇼팽10~12마디의 글자 겹침은 아직 남아 있으며 계이름 줄 시안에서 비교합니다.
