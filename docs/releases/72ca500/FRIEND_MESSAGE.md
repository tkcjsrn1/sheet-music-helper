# 친구 메시지 초안 — 배포 보류

ZIP을 전부 푼 뒤 악보헬퍼.exe를 실행하고 선명한 PNG/JPG 악보를 골라 「계이름 달기」를 눌러 주세요. PDF는 직접 넣을 수 없어요.
주황 점선은 「확인 필요」, 연한 글씨는 「주의」예요. 둘 다 원본과 대조해 주세요. 진한 글씨도 정답을 보장하지는 않아요.
화음의 일부 음이 빠질 수 있고, 곡 중간에 조표가 바뀌면 그 뒤 계이름이 틀릴 수 있어요. 사진은 종이를 정면에서 찍고 「사진 모드」를 켜 주세요.
문제가 생기면 「문제 신고용 저장」으로 만든 ZIP과 틀린 위치를 보내 주세요. ZIP에는 악보 원본이 들어 있으니 보내기 전에 확인해 주세요.
「Windows의 PC 보호」 창이 뜨면 제가 보낸 파일인지 확인하고 「추가 정보 → 실행」이 보일 때 선택해 주세요. 보안 기능을 끄지는 마세요.
스피커로 직접 듣기와 실제 다운로드 뒤 SmartScreen 화면은 아직 확인하지 못했어요. 이 메시지는 사용자 승인 전까지 보내지 않는 초안이에요.

이번 후보에서는 라벨 수정 창에서 왜 확인이 필요한지 설명을 볼 수 있어요. 일부 조바꿈 표기는 보완했지만 조바꿈 뒤 듣기 음높이는 아직 첫 조표를 사용하므로 맞지 않을 수 있어요. 친구 배포는 계속 보류합니다.
