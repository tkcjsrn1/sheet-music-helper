# 사람이 확인할 순서 — 새 베타

이 빌드는 우리끼리 검증하는 후보입니다. 실제 exe 클릭·사람 청취·실제 다운로드 SmartScreen은 자동 검사로 완료 처리하지 않았습니다.

1. 최종 ZIP을 새 폴더에 전부 풉니다. 이전 exe와 혼동하지 않게 build-info.json의 commit이 1ad8323으로 시작하는지 확인합니다. Python 설치 여부와 Windows 버전도 기록합니다.
2. 이미지 두 장(Aoharu1과 Beethoven Op18 Bravura1 등)을 선택해 변환합니다. 처리 중에는 쪽 번호/진행 막대와 회색 버튼이 보이고, 완료 후 「다음 쪽」을 누르면2/2와 현재 파일명이 바로 바뀌어야 합니다. 지연되면 화면 문구와 몇 초였는지 적습니다. N/P는 확인 필요·주의 글씨를 이동하고 입력칸에서는 글 입력만 해야 합니다.
3. 둘째 쪽 글씨를 수정·저장한 뒤 그 수정본 폴더를 다시 엽니다. 수정이 남아 있고 되돌리기가 되는지, 다른 쪽과 섞이지 않는지 확인합니다. 원본을 지우거나 덮어쓰지 않습니다.
4. 「음높이 듣기」를 시작·중지하고 실제 스피커에서 피아노 음색이 들리는지 확인합니다. 박자는 재생하지 않습니다. 실제 전달 경로에서 내려받은 파일에서 Windows 경고가 뜨면 화면을 남깁니다. 경고 유무를 추측하거나 보안 기능을 끄지 않습니다.

오류가 있으면 「문제 신고용 저장」으로 만든 ZIP과 문제 위치/처리 상태 문구를 함께 남깁니다. ZIP에는 원본 악보가 들어 있으므로 보내기 전에 확인합니다.
