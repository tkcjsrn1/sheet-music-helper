# 건반·계이름 줄 내부 베타 확인

친구·공개 배포 전 우리끼리 확인한다. 기존 베타와 설정은 보존한다.

- [ ] 라벨 선택·듣기를 시작해 **건반 강조와 실제 스피커 소리가 같은 음인지** 확인한다. 파랑은 선택, 주황은 현재 재생이다.
- [ ] 시작·다음 음·중지 때 **재생 지연**과 남은 강조/소리가 있는지 확인한다. 지금은 음높이 확인용이며 박자 재생은 없다.
- [ ] **표시 방식: 음표 옆 / 계이름 줄을 켜고 끈 뒤 계이름 달기를 다시 누른다.** 설정은 다음 변환부터 적용된다. 공간이 부족한 쪽은 전체가 음표 옆으로 돌아가고 안내가 보여야 한다.
- [ ] 라벨을 수정해 **저장 → 앱 종료 → 다시 실행 → 수정본 다시 열기**. 글씨·수정 이력·되돌리기와 표시 방식 유지 여부를 확인한다.
- [ ] 여러 쪽 처리 중 회색 다음 쪽/진행 표시, 완료 뒤 다음 쪽과 한글 N/P·영문 NumLock OFF F1을 확인한다.

**밀집 구간 배치 — 미해결:** 쇼팽10~12마디 같은 곳의 글자 겹침은 남아 있다. 계이름 줄이 공간 부족으로 원복된 쪽도 해결됐다고 보지 않는다.

스피커 청취와 실제 다운로드 SmartScreen은 사용자 확인이다. 자동검사/루프백 성공만으로 청취·SmartScreen을 통과 처리하지 않는다. 이상하면 문제 신고용 저장 ZIP을 남긴다.
