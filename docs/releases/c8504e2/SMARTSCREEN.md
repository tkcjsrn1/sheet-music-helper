# ZoneId=3 exe 화면 확인 — 2026-09-30

`c8504e2` exe의 바이트가 같은 사본을 `output/smartscreen-c8504e2/악보헬퍼.exe`에 만들고 `Zone.Identifier` 스트림에 `ZoneId=3`을 붙였다. 실행 전에도 `smartscreen.exe` PID 5220이 있었으므로, 실행 후 같은 프로세스가 남은 것만으로 SmartScreen 경고가 새로 뜬 것으로 판정하지 않는다.

처음 실행 때 `pwsh` 프로세스의 창 제목 **「파일 열기 - 보안 경고」**가 확인됐다. 게시자 확인 불가 안내였고, 「Windows의 PC 보호」 파란 SmartScreen 화면은 보이지 않았다. 경고창의 실행·취소 버튼은 누르지 않았다. 뒤이은 같은 ZoneId=3 사본의 직접 실행에서는 5초 뒤 `악보헬퍼.exe` 프로세스가 나타났고 GUI 창이 열렸다. [전체 화면 캡처](smartscreen_check.png)는 창이 열린 뒤 개인 데스크톱 내용이 보이지 않도록 앱 창을 최대화해 저장한 것이다. 검은 화면이 아니다. 캡처 뒤 실행 중인 악보헬퍼 프로세스는 종료했다.

이 검사는 로컬 사본에 인터넷 영역 표시를 붙인 재현이며, 실제 다운로드 ZIP을 다른 PC에서 실행한 결과가 아니다. 따라서 **실제 배포 경로에서 SmartScreen이 뜨는지·문구가 무엇인지는 미확인**으로 남긴다.
