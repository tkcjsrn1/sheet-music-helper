# 검사 도구의 실패 시도 (성공에 포함하지 않음)

- 파일 대화상자의 기존 파일명에 문자열을 이어 붙인 첫 시도: Windows 「파일 이름이 올바르지 않습니다」. 실제 파일명 칸 클릭→Ctrl+A→정확한 경로 재입력→열기 클릭으로 다시 선택했다.
- 다른 앱이 가린 좌표: `_native_click`의 `클릭 위치를 다른 창이 가립니다` 검사에서 입력0으로 차단. 대상 root33688292 대신2429598(자기 파일 대화상자) 또는 다른 앱26872212/PID39428을 관측했다.
- 다른 앱이 전면인 키 입력: `검사 사본 이외의 창에는 입력하지 않습니다`로 차단. 다른 앱에 키를 보내지 않았다.
- 전면/창 좌표 검사는 OS 창 수준이다. Tk 내부 어느 입력 위젯이 포커스를 갖는지는 이 도구로 직접 읽지 않았으므로 N/P 무반응을 제품 원인으로 확정하지 않는다.
- 기록 생성 때 합성 결과 JSON 파일명의 오타가 나서 중단했다. 올바른 기존 파일명으로 다시 읽어 보표6·라벨48을 확인했다. 인식 결과나 파일명 자체를 바꾼 것이 아니다.
- WAV 외부 업로드는 자동 승인 검토에서 차단돼 커밋하지 않았다. 로컬 원자료를 보존하고 수치/해시만 공유한다.
