- 빠진 가운데 머리 206 중 203은 같은 화음의 위 · 아래 머리 라벨이 **있다**. 이웃과의 세로 간격은 전부 1.0sp(3도 쌓기)
- 덧줄 구역 15.1% 대 오선 안 10.5%, 빈 · 꽉 찬 머리 차이는 작다(10.5 · 12.4%)

**누락이 큰 쪽의 공통점 — 기존 세트에서 찾았다.** 화음 ≥ 20인 32쪽에서 쪽 화음 누락률의 순위 상관: **평균 화음 크기 ρ = +0.62**(p < 0.001) · 화음 비중 +0.59 · sp −0.41 · 빈 머리 비율 +0.14(무관). 상위 쪽은 Clara 폴로네즈 2 · 3(누락 19~26%, 3화음 반주), Schumann op48(20%). 보류 세트의 Beach · Clara 트리오도 같은 성격(3음 이상 반주 화음)으로 보이지만 **보류 세트로는 원인을 재지 않았다**.

## 4. 수정안 후보 — 「라벨 둘 사이 가운데 행의 가로 잉크 폭」(사본 시뮬레이션만)

기각 · 보류와 다른 근거: 같은 보표 라벨 둘이 같은 기둥(|dx| ≤ 0.3sp)에 세로 2sp(5도) 간격이고 가운데에 라벨이 없을 때, **가운데 행의 가로 잉크 런**(오선 제거 영상)을 본다. 3화음이면 머리 폭, 빈 5도면 기둥뿐.
#193(덩어리 **높이**로 머리 수 추정)과 달리 위치는 이미 있는 라벨 둘이 정하고, 「본 상관」(보류, 모양 비교)도 쓰지 않는다. **추가만** 하므로 기존 라벨은 안 건드린다(오삭제 구조적으로 0).

## 5. 권장안 · 예상 효과 · 위험

**권장: 측정 한 번 더 뒤 구현 검토.** 「양 끝 라벨이 둘 다 check가 아닐 것」을 더해 음자리표 글리프 유령 6을 빼면 정밀도 약 94%(되찾음 ≈ 79 · 새 유령 ≈ 5) — 이 조건은 같은 표본을 보고 정한 것이라 **사본 재측정 + 음고 정답 대조(되찾은 자리의 음이름이 3도 위인지)**를 먼저 한다.
- 예상 효과: 화음 누락 403 → 약 324(Verovio 337 → 약 258). 3화음 가운데 머리만 — 4음 이상 화음의 둘째 · 셋째(간격 3sp 이상)는 대상 밖
- 위험: 새 유령(다른 성부 두 음 사이 · 빔이 가운데를 지나는 빈 5도), 되찾은 머리의 임시표 판정이 따로 필요(표기 틀림으로 옮겨 갈 수 있음)
- 보류 세트는 구현 · 병합 뒤 결과만 채점한다
