# [2] 슈베르트 보리수 Leipzig (606, 1522) 오삭제 원인 (2026-10-04 · 측정만, 제품 코드 무변경)

## (a) 위 머리에 가짜 원시 임시표가 잡힌 이유

화음: E4 (606, 1522) · B3 (606, 1548) · F4 (626, 1513) — 전부 빈 머리, E4 · F4가 2도라 F4가 오른쪽으로 비켜 있다(그림 `docs/review/schubert_drop/cases.png` 왼쪽).
F4의 임시표 창(왼쪽 0.55~2sp)에서 `_find_glyphs`가 **막대 1개(패치 x 24, 화음 기둥) + 고리 1개(E4 빈 머리 속)** 를 「♭」으로 읽었다(고리 중심 높이 41.5 → F4와 0.35sp 안이라 F4의 원시 임시표 ♭).
♭ 판정은 「창 안에 막대가 있고 + 고리」면 ♭이고, **막대와 고리의 위치 관계를 보지 않는다** — 기보에서 ♭의 세로획은 고리 왼쪽인데, 여기 막대는 고리 **오른쪽**(기둥)이다.
그 가짜 ♭ 때문에 `remove_accidental_ghosts`가 F4 왼쪽 1.11sp · 0.5sp 아래 빈 후보 E4를 「♭ 글리프」로 지웠다.

## 수정안 / 예상 효과 / 위험 / 필요한 승인

**수정안**: `_find_glyphs` ♭ 판정에 기보 조건 「막대가 고리 왼쪽(0.05~1.0sp)」 추가. 예상 효과: 가짜 ♭ 34 제거(슈베르트 오삭제 해소 — 가짜 ♭이 없으면 E4를 지울 근거가 없다), 진짜 ♭ 235 중 1 잃음(Joplin 겹친 ♭ — 표기 「라b → 라」 1곳 틀어질 수 있음).
대안(더 좁게): ♭ 판정은 그대로 두고 `remove_accidental_ghosts`에서 「지울 후보가 고리를 가진 빈 머리이고 그 고리가 주인 ♭의 고리와 같은 것」일 때는 지우지 않음 — 측정 필요.
**위험**: 표기 변화가 전 세트에 퍼진다(가짜 ♭ 34의 주인 표기가 바뀜 — 대부분 고쳐짐일 것이나 정답 대조 필요), PDF 스냅샷 변화. **필요한 승인**: 판정 변경.
