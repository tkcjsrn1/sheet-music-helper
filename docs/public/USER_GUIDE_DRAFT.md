# 악보헬퍼 사용 안내

## 변환하고 검토하기

1. 승인된 ZIP을 전부 푼 뒤 `악보헬퍼.exe`를 실행합니다. 「악보 파일 선택」 또는 「여러 이미지 선택」에서 PNG·JPG를 고릅니다. PDF는 필요한 쪽을 이미지로 저장합니다. 사진은 정면에서 촬영한 뒤 사진 모드를 켭니다.
2. 「계이름 달기」를 누릅니다. 여러 쪽 처리가 끝나면 이전·다음 버튼으로 이동합니다. 조표 머리말과 보표 수를 원본과 비교하세요. 음자리표 미검출·알토 경고가 나온 줄은 특히 주의합니다.
3. 주황 점선은 확인 필요, 연한 글씨는 주의입니다. N/P 또는 검토 버튼으로 이동합니다. 입력칸에서 쓰는 동안 N/P로 이동하지 않습니다. F1으로 단축키를 엽니다. 확실로 표시된 라벨도 원본을 확인하세요.
4. 라벨을 선택해 수정·삭제하고, 빈 곳을 클릭해 추가합니다. 되돌리기를 지원합니다. 수정본은 별도 폴더에 저장합니다. 「저장한 수정본 다시 열기」에는 해시가 일치하는 원본 악보가 필요합니다.

## 인식 정확도와 알려진 한계

정답을 알고 있는 컴퓨터 조판 악보로 재 본 값입니다. 여러분의 악보에서도 같다는 보장은 아닙니다.

| | 개발하면서 본 악보(20쪽) | 처음 본 악보(12쪽) |
|---|---:|---:|
| 표시 없이 「확실」로 나온 계이름이 맞았던 비율 | 98.4% | 97.0% |
| 계이름을 못 붙인 음 | 2.9% | 7.0% |
| 음이 없는 곳에 잘못 붙은 계이름 | 5.7% | 5.5% |

- 처음 본 조판 악보에서는 「확실」로 나온 계이름 100개 중 약 97개가 맞았습니다.
- 못 붙인 음 7.0%의 절반 이상은 화음이 아주 촘촘한 악보 한 쪽에서 나왔습니다. 그 쪽을 빼면 3.4%입니다.
- **「주의」나 「확인 필요」 표시가 붙은 음은 꼭 원본과 대조해 주세요.** 표시가 없는 음도 틀릴 수 있습니다.

### 틀리기 쉬운 악보

- **화음 왼쪽에 임시표가 엇갈려 붙은 곳:** ♯ · ♭ · ♮이 여러 줄로 놓이면 먼 줄의 임시표를 놓치거나 다른 음에 붙일 수 있습니다.
- **음표가 빽빽한 구간:** 음을 놓치거나 계이름 글자끼리 겹칠 수 있습니다.
- **한 줄에 성부가 겹치는 악보:** 두 성부가 음표 머리를 나눠 쓰거나 기둥이 위아래로 엇갈리면 화음 일부를 놓칩니다.
- **사진으로 찍은 악보:** 정면에서 선명하게 찍어 주세요. 상태에 따라 다시 찍어 달라는 안내가 나올 수 있습니다. 위 숫자는 조판 악보에서 잰 값이라 사진에는 그대로 적용되지 않습니다.
- **그 밖에:** 알토(가온) 음자리표, 곡 중간의 조바꿈 · 음자리표 바뀜, 겹임시표, 꾸밈음은 틀리거나 빠질 수 있습니다.

## 건반과 구간 반복

라벨을 선택하면 해당 건반이 파란색으로 강조됩니다. 「선택 영역 / 전체 음높이 듣기」를 누르면 재생하는 음과 건반이 주황색으로 표시됩니다. 「확인 필요 음은 듣기에서 제외」를 켜면 직접 수정한 음을 제외 대상에 넣지 않습니다.

시작 라벨과 끝 라벨을 고른 뒤 각각 「시작 음 지정」, 「끝 음 지정」을 누르세요. 「구간 반복」을 켜고 재생하면 해당 구간을 반복합니다. 빠르기는 0.5~1.5배이며, 바꾼 값은 다음 재생에서 적용됩니다. 같은 가로 위치의 화음은 함께 들립니다. 지금은 음높이 확인용으로 각 음에 같은 길이를 사용합니다. 박자와 쉼표를 반영한 재생은 2차 업데이트에서 다룰 예정이며 일정은 미정입니다.

출력 지연을 줄이기 위해 피아노 소리를 보낸 시각을 기준으로 악보와 건반 강조를 늦춥니다. 스피커·헤드셋에 따라 체감 시차가 달라질 수 있습니다. 싱크 조절 슬라이더는 공개 후보에 포함되지 않습니다.

## 계이름 줄과 파일 오류

「표시 방식」에서 「계이름 줄」 또는 「음표 옆(기본)」을 선택한 뒤 **다시 변환**합니다. 빈 공간이 부족하면 그 쪽 전체를 음표 옆에 표시합니다. 저장한 수정본을 열면 저장 당시의 표시 방식과 수정이 복원됩니다.

이미지가 너무 크다는 안내가 나오면 이미지 크기를 줄이거나 한 쪽씩 저장해 넣으세요. 소스 GUI의 PDF 경로에서 파일 손상 안내가 나오면 원본을 다시 저장하거나 필요한 쪽을 이미지로 내보내세요.

문제가 남으면 「문제 신고용 저장」으로 쪽·위치·기대한 음을 함께 알려 주세요. 신고 ZIP에는 원본 이미지가 들어갑니다. 원본 권리와 개인정보를 확인하고 공유하세요.

## 사용자 확인

본인 악보에서 변환, N/P, 수정 저장·재열기, 계이름 줄 전환을 확인합니다. 스피커나 헤드셋에서 음과 주황색 강조가 같이 오는지, 반복 경계와 빠르기가 예상대로인지 들어 봅니다. 다운로드 경고는 [SmartScreen 안내](SMARTSCREEN.md)를 참고합니다.
