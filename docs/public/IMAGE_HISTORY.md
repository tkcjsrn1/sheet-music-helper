## 재현과 빠진 범위

[수집 코드](evidence/inventory-history.py)는 `git log --all --root --full-history -m --no-renames --raw -z`의 구/새 blob과 NUL 경로를 읽고, cat-file로 크기, ls-tree로 현재 경로를 대조한다. 한글·공백·개행 경로 self-check를 포함한다. 파일 내용은 추출하거나 새로 렌더링하지 않았다. 합계와 분류 합도 검사했다.

로컬에서 도달 가능한 refs만 조사했다. reflog·도달 불가능 object·서버에서 이미 삭제된 refs·GitHub 첨부/릴리스/Actions artifact·개인 원본 F:/inputs는 포함하지 않는다. 대소문자 확장자14종 밖 파일이나 문서에 들어간 URL/텍스트·개인정보도 별도 검토해야 한다. 오늘 #442의 합성 캡처3개도 refs에 포함했다(원본 사용0, 생성기 확인). 문서 PR 자체가 미래 refs를 추가하므로 표는 기록한 시점의 스냅샷이다. 새 공개 후보 확정 시 다시 목록을 만든다.
