# 악보헬퍼

악보 이미지에 계이름을 붙이고, 틀린 라벨을 고치며 피아노 음색으로 음높이를 확인하는 Windows 프로그램입니다. 현재는 내부 공개 후보 `116f32d` 검증 단계입니다.

- PNG·JPG를 선택해 변환하고 여러 결과를 쪽별로 넘깁니다. 배포용 exe에서 PDF를 쓰려면 먼저 필요한 쪽을 이미지로 저장하세요.
- 주황 점선과 연한 라벨을 N/P로 훑고 라벨을 추가·수정·삭제할 수 있습니다. 수정본을 저장하고 같은 원본과 함께 다시 엽니다.
- 선택한 음은 건반에 표시됩니다. 시작·끝 음을 고르면 구간을 반복하거나 0.5~1.5배로 들을 수 있습니다. 화음은 함께 들립니다. 재생은 음높이 확인용이며 음마다 같은 길이를 사용합니다.
- 「음표 옆」과 「계이름 줄」을 선택합니다. 여백이 좁으면 그 쪽 전체를 음표 옆에 표시합니다.
- 큰 이미지는 크기를 줄이는 방법을 안내합니다. 소스 GUI에서 잘린 PDF를 열면 다시 저장할 수 있도록 안내합니다.

화음 일부, 임시표, 음자리표·조바꿈을 놓칠 수 있습니다. 알토 음자리표, 꾸밈음과 리듬은 지원하지 않습니다. 밀집한 부분의 글자가 겹칠 수 있으니 원본과 비교하세요. 사진은 정면에서 찍고 사진 모드를 사용하세요.

승인된 ZIP을 모두 풀고 「악보 파일 선택」→「계이름 달기」를 누르세요. [사용 안내](USER_GUIDE_DRAFT.md)와 [Windows 경고 안내](SMARTSCREEN.md)를 참고하세요.

문제 위치를 재현할 수 있으면 「문제 신고용 저장」을 사용하세요. ZIP에는 원본 이미지가 포함됩니다. 제공할 수 있는 악보인지 확인한 뒤 보내 주세요. [피드백 양식](../FEEDBACK_FORM.md)
