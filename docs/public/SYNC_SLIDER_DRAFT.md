# 소리와 화면 강조 조절 초안

## 조작

「음높이 듣기」 아래에 「화면 강조 시차」를 둔다. 기본 0ms는 현재의 **송신 후 220ms**를 뜻한다. 양수는 강조를 더 늦추고 음수는 앞당긴다. 예를 들어 소리가 화면보다 늦으면 +50ms부터 맞춰 본다. 범위 제안은 −220~+500ms, 10ms 단위, 「기본값」 버튼은 0ms로 복원한다.

## 코드 경계

기존 앱 설정에 정수 `audio_highlight_offset_ms` 한 개를 저장한다. 누락되거나 정수가 아니거나 범위를 벗어나면 0으로 시작한다. 재생 버튼을 누를 때 값을 캡처해 그 재생의 강조 예약에만 쓰고, 재생 중 설정 변경은 다음 재생에 적용한다. Tk에서 MIDI 콜백 송신 시각 + (220ms + 보정값)까지 기다린다. 이미 기한이 지난 콜백은 즉시 처리한다. 기존 token과 타이머 취소로 중지·쪽 전환·종료에서 이전 재생을 격리한다.

오디오 자체의 속도, 음높이, WAV·MIDI 출력, 악보 변환과 수정본 스키마에는 연결하지 않는다. 처음에는 앱 설정 하나로 두고, 장치별 프로필과 자동 보정은 범위 밖이다.

## 검증

설정이 없는 기존 사용자, 유효한 양수/음수와 잘못된 값, 기본값 버튼, 재생 중 값 변경과 중지 후 늦은 이벤트를 단위 검사한다. 기본값에서 현재 스케줄과 동일한지 확인한다. 루프백을 0.5/1/1.5배로 재고 중간값, ±50ms 개수, p95, 누락·불확실성을 기록한다. 블루투스와 스피커 체감은 장치별 사용자 확인이다. 간헐적으로 나오는 지연에 대해 보정값 하나가 해결을 보장하지 않는다.

코드와 화면은 검토용 초안으로 별도 관리한다.
