# 1차 공개 파일 목록

[경로와 SHA256 목록](PUBLIC_FILES.json)은 65be2ab에서 만든 검토본이다. 최종 검증한 PDFium 소스와 MIT LICENSE 등으로 목록의 경로와 해시를 갱신한 뒤 그 목록의 파일만 복사한다. 문서는 표에 적은 대상 경로에 둔다. 저장소 생성과 파일 복사는 사용자 결정 뒤에 진행한다.

소스 허용 목록은 GUI·CLI·메시지, modules의 18개 Python 파일, 의존성 목록, 버전 정보, Git 텍스트 설정이다. 프로젝트는 MIT LICENSE를 넣는다. #494에서 채택한 앱 아이콘은 자체 생성한다. 최종 소스 목록에 포함할 아이콘·spec 경로와 해시는 검증 커밋을 기준으로 확정한다. 내부 build.py는 private 픽스처를 쓰는 전체 검사에 의존한다. 공개 재현용 빌드 절차를 정리하고 검증한 뒤 포함한다.

기존 Git 이력, 원본 악보, 샘플, 스크린샷, 골든·픽스처, 내부 문서와 검증 기록, 신고 자료 및 빌드 산출물은 소스 복사에서 제외한다. 승인된 바이너리와 ZIP은 릴리스 첨부로 다룬다. 게시 전에 ZIP 고지와 동봉 파일의 해시를 다시 확인한다.
