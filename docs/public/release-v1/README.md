# 악보헬퍼

악보 이미지에 계이름을 붙이고, 틀린 라벨을 고치며 피아노 음색으로 음높이를 확인하는 Windows 프로그램입니다.

- PNG·JPG와 PDF를 엽니다. PDF에서 원하는 쪽을 고르거나 전체 쪽을 300dpi 기준으로 변환하고, 결과를 쪽별로 넘길 수 있습니다.
- 주황 점선과 연한 라벨을 N/P로 훑고 라벨을 추가·수정·삭제할 수 있습니다. 첫 저장에 필요한 폴더는 자동으로 만들며, 수정본을 같은 원본과 함께 다시 엽니다.
- 선택한 음은 건반에 표시됩니다. 시작·끝 음을 고르면 구간을 반복하거나 0.5~1.5배로 들을 수 있습니다. 화음은 함께 들립니다. 악보와 건반의 강조 시점은 재생에 맞춰 자동 보정합니다. 재생은 음높이 확인용이며 음마다 같은 길이를 사용합니다.
- 「음표 옆」과 「계이름 줄」을 선택합니다. 여백이 좁으면 그 쪽 전체를 음표 옆에 표시합니다.
- 큰 이미지는 크기를 줄이는 방법을 안내합니다.

화음 일부, 임시표, 음자리표·조바꿈을 놓칠 수 있습니다. 알토 음자리표, 꾸밈음과 리듬은 지원하지 않습니다. 밀집한 부분의 글자가 겹칠 수 있으니 원본과 비교하세요. 사진은 정면에서 찍고 사진 모드를 사용하세요.

[공식 릴리스](https://github.com/tkcjsrn1/sheet-music-helper/releases/latest)에서 받은 ZIP을 모두 풀고 「악보 파일 선택」→「계이름 달기」를 누르세요. [사용 안내](USER_GUIDE.md)와 [Windows 경고 안내](SMARTSCREEN.md)를 참고하세요.

오류와 제안은 [GitHub Issues](https://github.com/tkcjsrn1/sheet-music-helper/issues)에 남겨 주세요. 문제 위치를 재현할 수 있으면 「문제 신고용 저장」을 사용하세요. ZIP에는 원본 이미지가 포함됩니다. 제공할 수 있는 악보인지 확인한 뒤 보내 주세요. [피드백 양식](FEEDBACK_FORM.md)
