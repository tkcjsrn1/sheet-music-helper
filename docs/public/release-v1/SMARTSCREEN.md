# Windows SmartScreen 안내

Windows는 다운로드한 프로그램의 평판이나 게시자를 확인할 수 없을 때 경고할 수 있습니다. 장치 정책과 배포 파일에 따라 화면이 달라집니다. [Microsoft Defender SmartScreen 설명](https://learn.microsoft.com/en-us/windows/security/operating-system-security/virus-and-threat-protection/microsoft-defender-smartscreen/)

실행 전 공식 릴리스에서 내려받은 ZIP인지 확인하고, 릴리스에 적힌 SHA256과 비교하세요. 해시가 다르거나 백신이 탐지했거나 회사·학교 정책이 막으면 실행하지 말고 파일명과 경고 내용을 알려 주세요. Windows 보안 설정은 그대로 두세요.


공식 다운로드 경로와 SHA256은 공개 시 [릴리스 노트](RELEASE_NOTES.md)에서 확인합니다.
