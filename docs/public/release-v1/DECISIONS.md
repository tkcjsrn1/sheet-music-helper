# 공개 결정 기록

| 항목 | 결정 |
|---|---|
| PDF | C안 채택. pypdfium2/PDFium으로 교체한다. |
| 프로젝트 라이선스 | MIT를 유지한다. 동봉 의존성은 [제3자 고지](THIRD_PARTY_NOTICES.txt)를 따른다. |
| 공개 저장소 | 새 저장소 이름은 sheet-music-helper다. 사용자가 기존 비공개 저장소를 sheet-music-helper-dev로 이름 변경한다. 새 저장소에는 허용 목록만 새 첫 커밋으로 담는다. |
| 앱 아이콘 | Windows 글꼴 없이 직접 그린 #494 새 시안을 채택했다. |
