# 판단 2 — 알토(가온) 음자리표 보표 → 전체 「확인 필요」 (2026-10-04, DECISIONS §1-17)

도구 `tools/measure_alto_clef.py`(`product`로 제품 함수 판정). 머리 음자리표 검출 구간(`clef_start ~ clef_end`)의 잉크를 오선 기준으로 잰다.

| 정답 머리 음자리표 | 보표 | 잉크 위끝 − 윗줄(sp) 중앙 | 잉크 아래끝 − 아랫줄 중앙 | 세로 잉크 최장 중앙 |
