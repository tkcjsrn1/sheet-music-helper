**4. 주황 점선 상자는 어땠나요?**

- [ ] 도움이 됐다 — 점선부터 보니 틀린 곳을 빨리 찾았다

- [ ] 방해됐다 — 너무 많거나 악보를 가렸다
- [ ] 점선이 있었는지 모르겠다

점선이 없는데 틀린 곳이 있었나요?  [ ] 있었다  [ ] 없었다  [ ] 모르겠다
