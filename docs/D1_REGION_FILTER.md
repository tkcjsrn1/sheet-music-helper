# D-1 영역 필터 데이터층 (2026-10-03)

사용자 착수 지시와 TASKS의 filter_region 설계에 따라 전체 쪽에서 이미 인식한 라벨 문서에 사각형을 적용한다. 입력 악보를 자르거나 다시 인식하지 않는다. GUI/CLI 연결은 이번 범위가 아니다.

`modules.label_region.filter_region(doc, x1, y1, x2, y2)`는 음표 머리 중심 x/y가 선택 사각형 안에 있는 라벨만 사본에 남긴다. 끝점은 포함하며 역방향 드래그도 같은 영역으로 읽는다. 원본 범위 밖/너비·높이0/문자·불리언·NaN·무한대 좌표와 잘못된 원본·라벨 좌표는 오류로 알리고 조용히 넘기지 않는다.

원본 문서·보표·조표·음자리표·수정 이력은 보존한다. 라벨 순서와 확신도/사용자 수정 표시도 함께 유지하므로 이름과 확신도 목록이 어긋나지 않는다. 전체 쪽 영역이면 원본과 내용이 같고 중첩 객체는 독립된 사본이다. 비어 있는 정상 영역은 빈 라벨 목록을 반환한다. 화음이 경계에 걸리면 중심이 안쪽인 음만 선택한다. 음표가 인식 단계에서 삭제되는 것이 아니며 원본 문서는 그대로 남는다.

설계가 지정한 labels_io.py는 Claude 소유라 이번에는 고치지 않고 독립 데이터 모듈로 뒀다. 소유권 규약이나 판정 함수는 변경하지 않았다. 미래 연결에서는 보표/조표를 잃는 입력 잘라내기를 피하고, 배치 지표를 선택 영역 안에서 따로 재야 한다. UI·--region·영역 결과의 새 배치 검증은 아직 없다.
