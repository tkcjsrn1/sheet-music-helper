# D-4 표기 옵션

TASKS의 표기층 설계와 사용자 착수 지시에 따른 범위다. 글꼴·크기·색 조절은 이미 GUI/CLI에 있으므로 그대로 사용한다. 손가락 번호는 후속이다.

옥타브 표시는 기본 꺼짐이다. 켜면 고정도·이동도·영문 글씨 뒤에 계산된 음의 옥타브를 붙인다(도4, 시b3, C#5). 이동도 숫자는 으뜸음의 상대 옥타브가 아니라 실제 음의 옥타브다. 인식 음고/조표/계이름 JSON은 바꾸지 않으며 그림에만 적용한다. 사람이 고친 글씨는 완성된 표기로 취급해 자동 숫자를 덧붙이지 않는다.

데이터층 `note_namer.display_octaves()`는 순서·음표 객체를 보존한다. 꺼짐이면 원래 목록 자체를 반환한다. 사용자 수정 표시의 길이/종류가 맞지 않으면 거부한다. GUI 연결은 별도 PR이다. 켠 상태는 글씨가 길어지므로 겹침·머리 가림·거리/마디선 지표를 따로 보고, 새 음표 가림이 있으면 채택하지 않는다. 꺼짐 PNG/JSON은 바이트 동일이어야 한다.
