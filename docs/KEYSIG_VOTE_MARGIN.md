# 조표 투표 여유 — 분포와 「확인 필요」 경계 (2026-09-30, TASKS [2] · 측정 전용)

도구 `tools/measure_keysig_margin.py`(→ `debug/keysig_margin_*.json`). **제품 코드 무변경.** 배경 `DECISIONS.md` §1-5.

## 1. 무엇을 쟀나

**여유(뒤집힘 거리)** = 조표 교차 투표에서 막대 클러스터 **하나**의 인정/탈락을 바꾸는 데 드는 표 수 중, 그 한 클러스터만 바꿨을 때
**조표 판정이 실제로 달라지는 것**의 최솟값. 1이면 한 표로 뒤집힌다. (예전 표기 「바흐 −1」 = 여유 1, 「B♭m +1」 = 여유 2)

- 제품 `analyze_staves`가 `_vote_key_signature`에 넘기는 문맥을 그대로 가로챘다. 예전 도구(`measure_keysig_vote_margin.py`)는 `_analyze_one`을 직접 불러 제품 경로와 다를 수 있었다
- 쌍 · 사슬 · ♭ 규칙은 인정 집합만 바꿔 다시 도는 사본 — **매 입력 제품 판정과 대조, 불일치 0**(326건)

입력: 검증 20쪽(PDF 17 + Aoharu 3) · 사진 합성 세트 M1 통과 51장 · 기울였다 되돌리기(`measure_keysig_resample` 3악보 × 16각 + 0.5px 이동 × 5방식 = 255장).
정답 조표: 바흐 없음 · B♭m/D♭ ♭5 · Em ♯1 · Aoharu ♯2 · 사진 F_flat1 ♭1.

## 3. 경계 — 깨끗하게 갈리지 않는다

**여유는 「판정이 맞는가」가 아니라 「이 입력의 판정이 흔들리기 쉬운가」를 잰다.** 바흐는 맞게 읽을 때도 여유 1~2라서,
뒤집힌 판정과 안 뒤집힌 판정의 여유가 같은 구간에 겹친다. 경계는 「틀린 것을 얼마나 잡나 대 맞은 것을 얼마나 괜히 표시하나」의 선택이다.

| 경계 | 틀린 판정 잡음 | 맞은 판정도 표시 | 20쪽 표시 | 사진 표시 |
|---|---:|---:|---:|---:|
| 여유 ≤ 1 | 1 / 7 | 52 / 319 (16%) | 1 / 20 (바흐) | 7 / 51 |
| **여유 ≤ 2** | **6 / 7** | 139 / 319 (44%) | **2 / 20** (바흐 · B♭m 1쪽) | **17 / 51** (바흐 사진 전부) |
| 여유 ≤ 3 | 6 / 7 | 215 / 319 (67%) | 3 / 20 | 34 / 51 |

- **≤ 2가 유도되는 자리**: 틀린 판정 7건 중 6건이 2 이하이고 3에서는 하나도 더 안 잡힌다. 1과 2 사이에서 잡는 수가 1 → 6으로 뛴다
- 44%는 되돌리기 변형(일부러 흔든 입력)의 값이다. **흔들지 않은 20쪽에서는 2 / 20**, 둘 다 §1-5에서 불안정하다고 기록된 악보(바흐 여유 −1, B♭m +1)
- 못 잡는 것: Aoharu ♯2 → ♯1(여유 4). ♯ 사슬이 짧아진 경우로, 원래 판정으로 되돌리는 경로가 한 클러스터 넘게 필요하다
- 표본 한계: 뒤집힌 판정 7건 중 6건이 한 악보(바흐), 한 경로다. 경계 2의 근거는 사실상 바흐 하나다

## 4. 제안 (구현 안 함 — 사용자 결정)

1. **조표 「확인 필요」 표시** — 여유 ≤ 2면 판정은 그대로 두고 조표에 확인 필요 표시. 라벨 JSON `music`에 여유 값을 싣는다
   (값 계산은 `clef_keysig`에 — 내 담당; JSON 필드 · 화면은 Codex). 20쪽 기준 바흐 · B♭m 1쪽이 표시된다
2. **결과 이미지 머리에 「조표: ♭1로 읽음」** — 표시는 Codex 요청. 여유와 상관없이 늘 보여 주면 사용자가 조표 오판을 바로 알아챌 수 있다
   (바흐 ♭1 오판은 B 19개를 오류 없이 「시♭」으로 바꾼다 — 음이름 대조로는 안 보였다, §1-5)
3. 둘은 겹치지 않는다: 2는 모든 입력, 1은 흔들리기 쉬운 입력에 한 번 더 경고
