## 0. 측정 방법과 한계

- **대상 음표**: 제품 최종 음표 — 기존 파이프라인 + chord_rescue(`merge_additive`, FILL_ADDITIVE_MEASURE §8 연결 모양). chord_rescue로 새로 찾은 머리도 포함
- **정답**: PDF 임시표 글리프(`accidentals.*`, Emmentaler 두 이름 체계 `sharp/2 · flat/M2 · natural/0 · flatflat/M4` 정규화, 괄호 글리프 제외), 조표(`header_end` 왼쪽) 제외.
  글리프가 붙는 머리 = 오른쪽 0~4sp · 글리프 원점 y ±0.3sp의 가장 가까운 PDF 머리(원점 y = 음 높이). 붙을 머리가 없는 글리프 5개는 뺐다
- **판정**: **원시 판정**(마디 내 전파 전). `annotate_accidentals`에 음표마다 옥타브를 다르게 준 사본을 넣어 전파만 끈다 — 창 · 막대 찾기 · 후보 고르기는 제품 그대로
- **판정 입력값**: `accidental_detect._find_thin_bars` · `_find_glyphs`를 원본 모듈에서 가로채 읽었다(측정 함정 A-1 · B-4). 창 원점도 제품 식 그대로
- **RE:Aoharu 3쪽**: PDF 정답 없음. 원시 판정 임시표 0개(악보에도 임시표 없음 — 함정 D-4, 이 쪽에서는 아무것도 말할 수 없다)
- 「음표 없음」(정답 머리에 제품 음표가 없음)은 임시표 판정 문제가 아니라 검출 누락이라 분류하지 않았다

## 1. 재현 — D♭ 3쪽 (두 음표 모두 chord_rescue가 새로 찾은 머리)

판정 규칙(`_find_glyphs`): 창(음표 왼쪽 0.55~2.0sp, 위아래 ±2sp)에서 최장 런 1.5~3.2sp · 폭 ≤ 0.45sp인 열 묶음 = 막대.
이웃 막대 둘이 간격 0.3~0.95sp면 쌍 — **위 끝 어긋남 > 0.45sp 그리고 아래 끝 어긋남 > 0.45sp**면 ♮, 아니면 ♯.
쌍 세로 중심이 음표에서 0.35sp 안인 것 중 가장 가까운 쌍이 이긴다. **가로획 기울기 · 가로획 수는 판정에 쓰지 않는다.**

| | ♮ (961, 2897) → 음표 (986, 2900) | ♯ (1081, 2906) → 음표 (1110, 2909) |
|---|---|---|
| 창(행 × 열), sp | 77 × 28, 19.1 | 77 × 28, 19.1 |
| 막대 (중심x, 시작행, 끝행, 길이 sp, 폭 px) | (8.5, 6, 51, 2.41, 6) · (17.5, 15, 65, 2.67, 6) · **(27.0, 16, 76, 3.19, 2)** | (4.5, 6, 66, 3.19, 5) · (14.0, 6, 66, 3.19, 4) · **(27.0, 17, 76, 3.14, 1)** |
| 글리프 자기 쌍 | ♮ · 간격 0.47 · 위 +0.47 · 아래 +0.73 · 중심 −0.25sp | ♯ · 간격 0.50 · 위 0.00 · 아래 0.00 · 중심 −0.16sp |
| 셋째 막대와의 쌍 | ♯ · 간격 0.50 · 위 +0.05 · 아래 +0.58 · 중심 **+0.21sp** | ♮ · 간격 0.68 · 위 +0.58 · 아래 +0.52 · 중심 **+0.12sp** |
| 결과 | **♯** (셋째 막대 쌍이 음표에 더 가까움) | **♮** (같음) |
| 0.25 / 0.5 / 0.75px 이동 | ♯ / ♮ / ♮ | ♮ / ♯ / ♯ |

- **셋째 막대는 창 오른쪽 끝 열(x=27, 창 폭 28)** — 음표 머리 가장자리다. 붙은 화음이라 3도로 쌓인 머리 두 개의 왼쪽 가장자리가 세로 3.1~3.2sp로 이어져 막대 조건(≤ 3.2sp)을 겨우 통과한다
- 글리프 자체는 맞게 분류된다(♮ 어긋남 0.47/0.73, ♯ 0/0). 틀린 것은 **글리프 오른쪽 막대 + 머리 가장자리**로 된 가짜 쌍이 음표 y에 더 가까워서다.
  음표 y는 정답 음 높이보다 3px 아래(0.16sp)에 잡혔다 — 가짜 쌍 중심이 아래로 치우친 쪽이 이긴다
- 0.5px만 옮겨도 둘 다 맞게 바뀐다 → 문턱 경계(PR #84의 0.5px check에는 걸린다)
