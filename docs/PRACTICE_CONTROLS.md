# 구간 반복·빠르기 초안 (미병합, 2026-10-26)

사용자 무인 큐에 따라 새 의존성 없이 현재 같은 길이 음높이 재생을 확장한다. 박자·마디·쉼표를 추정하지 않으며 인식/JSON/출력 PNG를 바꾸지 않는다.

- 계이름 선택 후 「선택 음을 시작」「선택 음을 끝」. 같은 x의 화음 전체가 경계가 된다. 「구간 지우기」는 재생을 멈추고 경계를 지운다.
- 두 경계가 있으면 그 구간을 듣는다. 「구간 반복」을 켜면 중지할 때까지 반복한다. 두 경계 없는 반복·일부 경계·역순·제외된 경계는 안내 후 재생하지 않는다.
- 빠르기0.5~1.5배(작성자 선택:0.1배 단위), 기본1.0. 음높이는 그대로, 묶음 길이는0.28초/배율. 재생 중 빠르기·반복 변경은 다음 시작부터 적용한다.
- 중지는 범위를 유지한다. 새 쪽/편집/새 입력/다시 열기로 대상 문서가 바뀌면 범위와 반복을 지운다. 속도는 앱 세션 안에서만 유지한다. settings/라벨JSON에 새 필드는 넣지 않는다.
- 기존 세대 token과 시작시점 문서 사본, audio_plan의 원래 라벨 번호를 유지한다. 반복 첫 묶음도 실제 note-on 뒤 강조하며 중지/쪽 변경 뒤 늦은 사건을 무시한다.
- 시간 축은 별도 durations(묶음별 초 목록)로 받는다. 현재는 같은 길이이며 미래 리듬 입력의 JSON 계약/쉼표/붙임줄 처리는 CLI 협의 후 별도다.

검증: 데이터·WinMM 경계/취소·GUI 소비 RED→GREEN, 실제 Tk 합성 캡처, 기본3쪽 PNG/JSON6바이트 변화0, 골든711/PDF17/전체. 기능 PR은 draft·미병합. 실제 스피커·장치/Tk 지연은 사용자 확인이다.
