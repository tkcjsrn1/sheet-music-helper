# 문제 신고 ZIP 재현

`python tools/replay_report.py 신고.zip 새출력폴더`

신고에 묶인 원본·쪽 번호·음자리표·표기·조성·단조·사진 모드·글자 크기·색상으로 현재 소스 CLI를 실행한다. 결과는 `recognition.log`, `current/`, `report_diff.json`, `report_diff.md`다. 기존 폴더를 덮어쓰지 않는다.

- SHA-256이 다르거나 ZIP의 파일이 네 개가 아니면 중단. 추가 파일·중복·경로 탈출·암호 ZIP은 실행/추출하지 않는다.
- 조표·음자리표·오선·원본 정보·전체 라벨을 비교한다. 같은 좌표에 여러 라벨이 있으면 묶음째 보여 준다. 차이 0은 현재와 신고 당시의 일치이고 정답 보장이 아니다.
- 사람이 고친 라벨/영역 필터가 있는 신고는 그 의도적 차이도 포함된다. 해당 차이를 인식 회귀로 세면 안 된다.
- 신고에 개인 글꼴 경로·범례 설정이 없으므로 PNG 바이트 재현은 보장하지 않는다. 재현 대상은 JSON 인식 결과다. 저장된 설정이 실제 실행 당시와 다르면 도구가 이를 복원할 수 없다(오래 열린 #44의 별도 문제).
- 제품 인식 경로·문턱값·골든은 바꾸지 않는다.


여러 신고 ZIP의 접수 요약은 [베타 신고 요약 도구](BETA_FEEDBACK_INTAKE.md)를 사용한다. 단일 재현도 신고 당시 집계를 reported_summary.json에 남기고 성공하면 report_diff.json에 당시/현재 집계를 함께 기록한다.
