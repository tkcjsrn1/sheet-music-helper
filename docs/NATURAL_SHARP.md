## 1. 왜 「둘 다 > 0.45」가 Verovio ♮에서 31~40% 미달하나

글리프 상자 안 두 막대(제품 판정 입력 그대로, 두 획 찾은 글리프 ♮ 524 · ♯ 408):

| | ♮ 위끝 차 dt 최소 / 중앙 | ♮ 아래끝 차 db 최소 / 중앙 | ♮ 「둘 다 > 0.45」 | ♯ dt 최대 | ♯ db 최대 |
|---|---|---|---:|---:|---:|
| LilyPond | 0.00 / 0.72 | 0.41 / 0.72 | 364 / 375 | 0.05 | 0.31 |
| Bravura | 0.00 / 0.67 | 0.22 / 0.58 | 53 / 76 | 0.06 | 0.06 |
| Leipzig | 0.28 / 0.72 | −0.06 / 0.67 | 44 / 73 | 0.22 | 0.11 |

정상 ♮은 왼쪽 획 위끝 = 상자 위끝, 오른쪽 획 아래끝 = 상자 아래끝이고 「안쪽 끝」(왼쪽 아래 · 오른쪽 위)은 상자 안 약 0.6sp에서 끝난다.
미달한 ♮은 **한쪽 끝 하나**가 0.2~0.4sp 밀려(Bravura 왼쪽 획 위끝 비스듬함 · Leipzig 오른쪽 획 아래끝 · LilyPond 앞 머리에 붙음) 위 또는 아래 차 하나만 작아진다 —
그림 `01_natural_failing_product.png`(30칸 전부 또렷한 ♮, 제품은 ♯로 읽음 — Claude 눈 판정).

## 2. 조판에 무관한 성질 — 두 획 중심의 어긋남 dt + db

기보 규칙: ♮은 왼쪽 획이 위로, 오른쪽 획이 아래로 — **반대 방향으로 어긋난** 두 획. ♯은 두 획이 같은 높이(두 획 모두 위아래로 뻗음).
한쪽 끝이 밀려도 합은 버틴다.

| | ♮ 최소 / 1% / 중앙 | ♯ 중앙 / 99% / 최대 |
|---|---|---|
| LilyPond | **0.51** / 0.93 / 1.44 | −0.34 / −0.10 / **0.00** |
| Bravura | **0.61** / 0.61 / 1.28 | −0.39 / −0.16 / **−0.11** |
| Leipzig | **0.50** / 0.62 / 1.39 | −0.22 / −0.04 / **0.06** |

**문턱 0.28** = (♯ 최대 0.06 + ♮ 최소 0.50) / 2 — 부호 있는 값이라 기하평균 대신 가운데, 양쪽 여유 0.22. 그림 `02_sharp_closest.png`(합이 가장 큰 ♯ 18칸 — 전부 또렷한 ♯).
기각: min(dt, db)(♮ 최소 −0.06이 ♯ 범위와 겹침) · max(dt, db)(♮ 최소 0.33 · ♯ 최대 0.31 — 0.02 차).

## 4. 새 조건이 만든 새로 틀림 — 원인

보지 않은 악보, 새 조건 단독(그림 `nat_unseen/`): 월광 2쪽 (1736,2578) · 월광 18쪽 (368,3028) (2129,3223) · 빗방울 4쪽 (788,368) — ♯ 글리프를 ♮로(+ 전파 2), 월광 11쪽 (1489,2507) 겹올림 「파# → 파」.
판정 입력을 찍어 보니 **고른 쌍이 ♯ 글리프의 두 획이 아니다** — ♯ 한 획 + 오른쪽 머리 가장자리 · 기둥(쌍 간격 0.72~0.91sp, 또는 창 오른쪽 끝 막대). 그 쌍이 위아래로 어긋나 합 조건을 넘었다. 제품 조건에서는 우연히 ♯이었다.

| 쌍 간격(sp) | ♮ 진짜(세 조판) | ♯ 진짜 | 새로 틀린 가짜 쌍 |
|---|---|---|---|
| 최대 | 0.63 | 0.54 | 0.72 · 0.83 · 0.84 · 0.91 (+ 창 끝 0.50 · 0.72) |

- **수락안과 함께면 남는 것은 1건 + 전파 1**(월광 18쪽 (368,3028) — 「수락안 → 수락안 + 새 조건」 차이). 나머지는 c12가 머리 가장자리 막대를 빼서 막힘
- 보완 후보(안 돌림): 「쌍 간격 ≤ 0.67 = √(0.63 × 0.72)일 때만 ♮」 — 가짜 3건을 막지만 여유가 얇고 가짜 근거가 보지 않은 두 곡뿐. 창 끝 막대 2건은 못 막는다
