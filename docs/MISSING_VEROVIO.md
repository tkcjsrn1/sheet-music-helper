## 4. [3](c) 덩어리 높이로 머리 수를 추정해 「추가만」 — 정밀도 부족 (2026-10-04, `tools/measure_dense_chord.py`)

덩어리 = 오선 제거 → 타원 0.5sp 열림(기둥 · 얇은 획 제거) 뒤 8연결 성분. 대상 = **지금 라벨이 1개 이상 걸린 덩어리**(chord_rescue처럼 이미 잡힌 덩어리만 넓힘, 정답 머리 없는 덩어리 포함).
추정 머리 수 n = round((높이 − 1sp) / 단계) + 1. 더함 = n − 걸린 라벨 수(유령 포함), 진짜 = min(n, 정답) − 라벨 붙은 정답.

| | 값 |
|---|---|
| 라벨 걸린 덩어리 | 6,928(정답 머리 없음 277) · 머리 2개 이상 98(정답 머리 201 · 라벨 154) |
| 이 덩어리들 안에서 되찾을 수 있는 누락 | **47**(Verovio 「모양 판정」 478 · 화음 261의 일부) |
| 3도 가정(단계 1.0sp) | 더함 74 · 진짜 37 · **정밀도 50%** · 유령 37 |
| 2도 가정(단계 0.5sp) | 더함 199 · 진짜 47 · **정밀도 24%** · 유령 152 |
| 정답 머리 수별 덩어리 높이 sp(5 · 50 · 95%) | 1개 1.00 · 1.06 · 1.11 / **2개 1.06 · 2.00 · 2.06** / 3개 3.00 · 3.00 · 3.05 |

- 2도 화음은 두 머리가 좌우로 엇갈려 높이가 한 머리(1.06sp)와 같은 덩어리가 있다 — 높이만으로는 2도와 단독을 못 가른다. 과다 추정 278은 대부분 빔 · 붙임줄 · 덧줄이 붙어 키가 커진 단독 머리.
- **나머지 누락은 라벨이 하나도 안 걸린 덩어리에 있다** — 「이미 잡힌 화음 넓히기」로는 닿지 않는다(그건 머리 후보 생성 단계 문제).

**수정안 / 예상 효과 / 위험 / 필요한 승인**: 높이 단독 추정은 기각(정밀도 50% · 24% — 유령이 진짜만큼 생김). 넓히려면 머리 자리마다 **머리 모양 본 상관**(그 쪽 단독 머리를 본으로, 높이 반칸 단위로)으로 위치까지 확인해야 하고, 효과 상한은 47(이미 잡힌 덩어리) — 더 큰 몫(라벨 없는 덩어리)은 머리 후보 생성의 모양 판정 문턱 문제로 따로 재야 한다. 위험: 유령 머리 · 음고 오류. 측정은 승인 불필요, 구현은 승인 필요.
