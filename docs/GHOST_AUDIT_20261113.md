# 유령 라벨 후속 측정 — 2026-11-13 KST

공개 후보 65be2ab의 인식 경로를 기준으로 측정했다. 제품 파일은 수정하지 않았고 공식 보류 세트는 실험에 쓰지 않았다. 제품 전처리와 인식은 공개 후보 소스에서 실행했으며, 경고 후보는 출력된 라벨을 사후 채점했다.

## 꼬리 모양 경고

개발 악보의 꼬리 16개와 실제 음표 201개로 비교 영상을 고정하고, 다른 악보에 동일한 비교를 적용했다. 기준은 두 세트 사이에서 바꾸지 않았다.

| 별도 입력 | 기존 「확실」 유령 | 새 경고가 잡은 유령 | 실제 음표에 새 경고 |
|---|---:|---:|---:|
| Mutopia PDF 8쪽 | 40 | 3 | 0 |
| 추가 조판 16쪽 | 6 | 0 | 0 |

Mutopia 수치는 일반 크기 머리로 채점한 기존 집계다. 원본 확대와 PDF 글리프에서, 경고가 걸리지 않은 두 행은 유령이 아니라 작은 실제 음표임을 확인했다(Schubert Impromptu 2쪽 (843,1212), (1308,2270)). 따라서 표의 40에는 이 두 행도 포함된다. 새 경고 3건은 실제 유령이며, 꼬리 1건·임시표 1건·음표 머리 옆 1건이었다. 별도 입력에서 꼬리 경고의 효과가 작아 적용을 보류한다.

## 2/2 박자표

추가 조판 16쪽의 「확실」 유령 6건은 모차르트 K.80의 같은 2/2 기호에 붙었다. 기존 리듬 시제품의 C·2/2 검출 모델과 문턱으로 개발 조판 20쪽, 추가 조판 16쪽, Mutopia PDF 8쪽을 검사했다. 검출된 기호 영역에 「확실」 6건과 기존 「확인 필요」 6건이 들어왔다. 실제 음표와 대응되는 라벨은 0건이었다. 조판 정답의 음표 머리 중심도 31개 검출 상자 안에 0건이었다.

2/2 기호 양성 예시는 모델 개발에 쓰였던 모차르트 K.80 한 곡의 두 글꼴(8기호)에 집중돼 있다. Mutopia에서는 C 기호 하나만 검출돼 2/2 재현율을 추가로 확인할 수 없었다. 별도 PDF 세 곡에서는 2/2 기호 10개 중 베토벤 「비창」 1개만 찾았다. 슈베르트 즉흥곡과 베토벤 「월광」에서는 검출이 없었다. 다른 악보의 재현율이 낮아 적용을 보류한다. 사진은 검사하지 않았다.

## 빔

이전 Mutopia 결과에서 빔 위·사이 유령으로 보인 25좌표를 현재 소스의 실제 경고 경로에서 다시 확인했다. 17개는 이미 경고가 붙었다. 나머지 8개는 모두 빈 머리로 검출됐으며 기울어진 빔 마스크의 영역 조건을 통과하지 못했다. 두께 문턱은 이 8개를 설명하지 않는다. 베토벤 2개는 아래 띠에만 마스크가 있었고, 슈베르트 6개는 세 띠 모두 마스크가 비었다. 별도 겹빔 틈 검사에서 베토벤 2개는 위 막대 길이 1.20sp가 기존 1.5sp보다 짧았다. 슈베르트 6개는 막대 두께가 기존 하한 0.4sp보다 작았다. 과거 오삭제 반례인 월광 2쪽 (1030,2640) 온음표도 두께 검사에 걸렸고, 실제 라벨은 현재 남아 있었다. 문턱을 낮추는 방식은 추가 검증 없이는 채택할 수 없다.

별도 PDF 집계는 meter-independent.tsv에, 빔 두께·가로 길이와 온음표 반례는 beam-gap-existing-values.tsv에 있다.
