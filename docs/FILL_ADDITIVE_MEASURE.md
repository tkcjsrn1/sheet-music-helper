## 8. 연결 요청 (Codex, `main.py` · `gui.py`) — WORKLOG에 같은 내용

`run_page`(와 gui의 같은 흐름)에서 첫 파이프라인이 `notes_with_solfege` · `accidentals` · `diag_rows`까지 끝난 뒤:

1. 두 번째 파이프라인: `noteheads2 = chord_rescue.detect_noteheads_rescue(result, contexts=contexts)` → `drop_beam_ghosts` → `drop_offstaff_ghosts` →
   `calculate_pitches` → `annotate_accidentals` → `remove_accidental_ghosts`(filled · flagged 포함) → `to_solfege_batch` → `diagnose_labels` · 표시 둘(첫 파이프라인과 **같은 순서 · 같은 인자**)
2. `added, deleted = chord_rescue.merge_additive([(n.x, n.y) for n in 첫 결과], [(n.x, n.y) for n in 둘째 결과], sp)` — `sp = median(s.spacing for s in result.staves)`
3. 첫 결과에서 `deleted` 번호를 **음표 · 임시표 · 진단 행에서 함께** 빼고, 둘째 결과의 `added` 번호를 붙인다.
